# 全局个人艺术库采集、审批与风格词导出

## 用户纠正

- 艺术库是本机唯一的个人总库，不再创建或绑定专属艺术库 AI、专属 Chat 或专属会话。
- 任何普通对话都可以让当前 AI 调用同一套艺术库工具完成联网图片收集、识图、分类和候审提交。
- 第一版只收集图片。用户只需说“收集某位艺术家、作品或风格”；默认 12 张，单次最多 30 张，明确指定数量时按用户输入执行。
- 原图直接下载并保存在本机。每张图片由支持视觉输入的当前模型填写标题、作者、日期、来源、AI 识读、标签、构图、色彩、Prompt 草稿、建议分类和置信度。
- AI 只能把完整条目放入审批目录。人类可以修改后采纳、驳回或暂缓；采纳移动到对应分类，不存在的分类自动创建，驳回删除候审条目。
- 单分类风格导出不调用 AI。系统只汇集该分类全部已入库作品的风格关键词，清理空白、去重并保持首次出现顺序，输出逗号分隔文本。
- 风格词可以复制或作为可见文本送入任意 AI 对话；第一版不生成库级概念 Prompt，不做权重、频率排序、AI 总结或自动改写。

## 对旧发现的取代

`2026-08-06-local-creative-libraries-and-art-chat.md` 中“艺术库增加独立、纯净的 Chat 页面”和按普通项目绑定艺术库 Chat 的语义被本记录取代。既有静态 Chat 入口可以继续作为尚未迁移的前端遗留，但不能再指导 Runtime（运行时）、持久化或工具设计。

旧记录中“本批不做联网采集、审批落库和自动分类”只描述 2026-08-06 当时批次，不再是当前产品冻结项。

## 第一版边界

- 搜索覆盖是 Best Effort（尽力而为）：外部页面可能拒绝访问、动态渲染或没有可下载图片；稳定性要求是失败分类、零半成品、部分成功披露和可重试，不是保证互联网任意内容都能抓取。
- 当前模型不支持视觉输入时，候选保留在内部采集区并失败关闭，不得根据网页摘要冒充识图结果。
- 审批区和正式分类只由 Art Library Runtime（艺术库运行时）写入。模型不能提供绝对路径、相对逃逸路径或直接绕过审批。
- 现有静态 Art Atlas 是首批迁移输入，不继续作为可写事实源；外部 `D:\CodexW\my-art` 只作为来源证据，不成为 Runtime 依赖。
- 本批不修改生产前端布局；审批页和艺术库页的真实数据接入由相邻 `workspace-ui` 后续消费稳定合同。
