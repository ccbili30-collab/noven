# 灵感库双库与本机热度

## 用户确认

- 取消原有世界观、小说题材、历史架空、奇幻、科幻和角色等一级分类。
- 灵感库只保留“启发 / 幻想”两个库。
- “启发”保存问题类内容或提出有趣设想的问题；“幻想”保存异世界、世界观以及其他陈述式有趣点子。
- 第一版采用最简单、可预测的规则：中文或英文问号结尾进入“启发”，其他完整陈述句进入“幻想”。
- 页面提供热度排名，不需要扩展为公共社区。
- 两个库各整理 50 条，共 100 条；这是最终总量，不是在现有样本之外再增加 100 条。
- 保留用户已经给出的两条“启发”和原有 25 条“幻想”，其余内容从真实可访问的公共网页提炼并重新创作为中文完整句。

## 实现解释

- 既有本机 Store 没有账号、公共计数或联网人气来源，因此热度只能明确标记为本机热度。
- 本机热度采用收藏 2 分、喜欢 1 分；同分保持条目原有顺序，不伪造远端参与人数。
- 旧 JSON 的 `category` 继续读取以保持兼容，但页面分类只由句末问号规则决定，不做用户数据迁移。
- 原有科幻、历史、穿越等词继续作为标签和搜索依据，不再显示为一级库。
- 公共网页只作为灵感触发点与溯源地址，不代表网页原文支持重新创作中的虚构剧情；页面也不显示或推断网络热度。
