# 干净上下文独立审查 Skill

> 2026-08-03 纠正：该能力属于开发 CreatX 的 Codex 协作流程，不属于 CreatX 用户侧 Creative Skills。应用内源码、安装允许列表和验收项已移除；方法迁移到本机 Codex Skill `clean-context-review`。以下内容仅保留为被纠正的发现记录，不再构成 CreatX 产品规格。

## 用户目标

用户希望主 Agent 在复杂创作或工程问题中按需创建一个没有任务历史的独立审查者。主 Agent 只提供当前问题所需的大局信息和证据，避免审查者被既有诊断、修改路线或长会话惯性污染。

审查者的理解可以错误。主会话收到结果后可以用既定产品语义或新增证据提出纠正，再交由干净复审者重新判断；纠正不能只是要求对方同意。

## 接受的工作流

1. 主 Agent 组织最小审查包，不附完整聊天、当前结论或偏好修复。
2. 使用真实隔离 Agent 工具建立只读初审；没有隔离工具时失败关闭。
3. 主 Agent 对照权威规格和证据检查初审。
4. 如有误解，保留初审原文并形成纠正包。
5. 由于 Cline `spawn_agent` 不提供可恢复子 Agent 句柄，使用第二个干净 Agent 复审，而不伪称继续同一子会话。
6. 最终保留初审、纠正，以及保留、修改、撤回或争议结论。

## 创作判断边界

独立不等于脱离产品语义。原创路线允许增加新事实；此前未出现不等于错误。错误主要是前后冲突、擅自填死明确未知项、因果断裂、违反来源边界，或新增事实无法持久化并传播给下游。原著整理与二创扩展必须使用各自不同的事实权限。

## 工程边界

本批只实现应用内置 Skill、安装允许列表和自动合同测试，不启用生产 `spawn_agent`。当前 Cline Adapter 明确配置 `enableSpawnAgent: false`，且既有 Kernel Lab 暴露取消传播和后代用量问题。在 Runtime 提供受控隔离审查入口前，Skill 必须明确失败关闭，不能在当前会话自审后冒充独立审查 Live。
