# 工作台可见范围发现记录

## 用户意图

用户需要让一个已注册工作台只展示指定范围的真实文件。例如隐藏全部图片，只显示 Markdown。规则由对话中的 AI 通过正式工作台工具设置，不要求第一版增加手动配置界面。

工作台仍然只是项目真实文件的策展 Projection（投影）：筛选不能移动、复制、删除、改名或重写项目内容，内置 `builtin:files` 继续提供完整的普通文件兜底视图。

## 已确认决定

- 可见范围同时支持包含和排除规则。
- `autoIncludeNewFiles` 是显式开关，默认 `true`。
- 开启时，之后新增且符合规则的文件自动进入工作台。
- 关闭时，保存规则的瞬间冻结当前符合规则的文件清单；之后新增文件默认不进入。AI 再次设置规则时重新形成清单。
- 删除或移走真实文件后，冻结清单不伪造文件，条目自然消失。
- 第一版由 AI 工具写入，不增加 Renderer（渲染层）配置表单。

## 实现边界

- 新规则使用严格 V3 记录；V1/V2 保持兼容读取，不后台迁移。
- 规则只匹配注册文件夹内的相对文件路径。目录只在拥有可见后代时作为结构节点出现。
- 匹配支持普通相对路径以及按路径段解释的 `*`、`?`、`**`；统一使用 `/`，Windows 下大小写不敏感。
- 排除优先于包含；空包含表示允许全部普通展示文件。注册工作台既有的 JSON 隐藏规则继续作为不可绕过的展示门禁。
- 已登记交互主页若会被新规则隐藏，更新失败关闭且不写盘。被过滤的 HTML 也不能通过工作台展示命令旁路打开。
- 内置“文件”工作台不接受规则，不改变公开 `WorkbenchProjection` 合同。

## 非目标


- 不增加前端规则编辑器或开关。
- 不建立第二份文件内容、标签数据库或文件所有权。
- 不允许脚本、正则表达式、绝对路径、项目外路径或直接编辑 `.creatx`。
- 不承诺外部 Provider（模型服务）会在本批自主选择工具；该项需要单独 Live（真实运行）证据。
