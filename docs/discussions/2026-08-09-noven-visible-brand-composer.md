# 诺文可见品牌与 Composer 控件整理

日期：2026-08-09  
主能力线：Workspace UI（工作区界面）  
状态：Accepted（已接受）

## 用户意图

- 产品当前所有用户可见的 `CreatX` 品牌改为“诺文”。这是临时品牌调整，不迁移内部兼容身份。
- Composer（消息输入器）原先悬在输入框上方的 Skill 插槽移到“自由 / 审批”权限控件旁边，前置启用勾选缩小。
- 发送键旁不应另增停止控件；发送后原发送按钮在同一位置切换为灰色停止方块，运行结束后恢复发送箭头。
- “点子库”改名为“灵感库”；“传承库”继续表示内置的创作方法与艺术欣赏资料，不合并到灵感库。
- 全产品使用 JetBrains Mono；因为该字体不含完整中文字形，中文使用系统中文字体回退，不能宣称中文来自 JetBrains Mono。

## 接受边界

- 窗口、导航、启动与错误文案、艺术库、安装包、可执行文件、快捷方式和卸载显示名使用“诺文”。
- 保留 `appId: com.creatx.desktop`、`@creatx/*`、`window.creatx`、`creatx-*://`、LocalStorage 键和现有 Profile（用户数据目录）。本批没有数据迁移、协议迁移或安装身份迁移。
- JetBrains Mono 字体文件随桌面 Renderer（渲染进程）和内置艺术库一起离线打包，并保留 OFL（开放字体许可证）文本。
- 停止态继续调用现有取消链，不改变 Run（运行）状态机或取消语义。
- 用户气泡不显示“你”；修改、重发、删除默认只显示图标，Hover（悬停）或键盘聚焦时显示文字。
- 对话图片使用明确圆角，对话滚动条轨道透明，不保留截图中的白色底条。

## 明确不做

- 不重命名源码类型、包、环境变量、内部协议、日志前缀或磁盘数据目录。
- 不重写 Cline 历史、模型 Prompt 或已有项目文件中的历史品牌文本。
- 不把“传承库”改成用户收藏库，也不合并三种资料库的数据。

## 后续澄清

同日用户指出，首轮实现把停止入口错误地做成了发送按钮旁的独立文字按钮。本记录以上述“原位替换”规则取代该实现；独立 `.wb-stop-run` 不再属于接受设计。用户同一张标注图中的“去掉你、操作图标 Hover 显示文字、图片圆角、滚动条无白底”也属于本批明确要求，不得只实现品牌与 Skill 移位。
