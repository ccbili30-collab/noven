# 非阻塞错误的恢复提示

用户确认将当前高频但不需要用户处理的“图片任务请求无效。”和“运行时发生错误。”改为短暂恢复提示：先以橙色显示 6 秒，再以绿色“已恢复！”显示 2 秒并自动隐藏，不等待或校验后续任务结果。该规则只匹配这两个用户可见摘要；余额不足、凭据、权限、持久化、项目冲突及其他真实阻塞错误继续沿用现有红色与持久展示。

本批只改变 Renderer（渲染层）提示投影，不修改 Runtime（运行时）错误码、Timeline（时间线）持久事实、任务状态或 Provider（模型服务）行为。
