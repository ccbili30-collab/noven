# 对话打开时的一次性底部定位

日期：2026-08-09（Asia/Shanghai）

主能力线：Workspace UI（工作区界面）

## 用户意图

用户要求打开对话时自动拉到最下面，并且打开动作只拉一次。经代码与既有规格核对后，确认采用以下精确语义：

- 每次真正进入或切换到一个会话，在该会话历史首次非空提交到 DOM 后自动定位到最底部一次。
- 同一会话打开周期内，React 重渲染、工作台开关、窗口缩放和历史后续提交不得再次触发“打开定位”。
- 离开该会话后再次进入，形成新的打开周期，可以再次定位一次。
- 本决定只限制打开定位的次数，不取消既有底部黏附：用户仍在底部时，AI 流式回复继续贴底；用户向上滚动后停止跟随并显示“回到最新”。
- 空会话不消费一次性定位；该会话稍后首次出现消息时仍执行定位。

## 取代关系

本决定取代 `ACC-WUI-042` 旧证据说明中的“长历史首次加载不自动跳到底部”，但不取代 `WUI-033` 的底部黏附、上滚停跟和“回到最新”规则。

## 实现与验收边界

- 权威实现继续由 `ConversationScrollController` 独占，不在 React Effect、CSS 或消息投影中复制规则。
- 验收覆盖长历史首次打开、同一打开周期只定位一次、空历史延迟出现消息、离开再进入重新定位，以及既有底部跟随和上滚停跟回归。
- 不改变 Session（会话）持久化、Timeline（时间线）合同、Provider（模型服务）、消息内容或工作台布局。
