# 工作台视觉批注发现记录

## 用户意图

用户希望在工作台当前可见内容上直接框选或自由涂画，再把“当前画面＋绘画蒙版”作为待发送图片加入对话，并用自然语言告诉 AI 要修改什么。图片、小说、Markdown、HTML 和其他已能预览的格式统一走视觉模型，不建立第一版语义选择。

## 已确认语义

- 批注只覆盖当前可见工作台区域，不滚动拼接完整长文档。
- 蒙版不修改源文件；矩形和笔画是可撤销、可重绘的批注草稿。
- 点击“加入对话”后才生成合成 PNG，并进入现有待发送附件；不自动发送或调用模型。
- 第一版支持矩形、自由画笔、三档粗细、撤销、重做、清空和退出。
- 颜色使用 HSV 全色调色盘：色相条、饱和度/明度二维区域、十六进制值、最近颜色和作品像素吸管。
- 第一版批注不支持透明度，保持完全不透明。
- HTML 不做 DOM/组件检查，不注入语义桥；只捕获真实显示像素。

## 非目标

- 不修改、覆盖或另存作品图片。
- 不做图层、橡皮、箭头、文字、渐变画笔或完整艺术软件。
- 不把 Renderer 生成的 Base64 直接冒充已授权附件。
- 不允许截图包含聊天、项目导航、审批或相邻隐私区域。
- 非视觉模型必须失败关闭并保留用户草稿，不用文本推测替代视觉理解。
