| ID | 规则 | 场景 | 通过条件 |
| --- | --- | --- | --- |
| ACC-VID-001 | VID-001 | 粘贴裸链接、分享句与已有草稿 | 空输入生成明确分析请求；已有草稿不被改写；无自动发送 |
| ACC-VID-002 | VID-002 | 公网抖音、私网、回环、DNS 漂移与重定向 | 只有合法公共目标进入下载；失败零媒体副作用 |
| ACC-VID-003 | VID-003 | 当前抖音页面签名提取成功、拒绝与页面变化 | 成功使用平台真实详情；失败分类且不猜测 |
| ACC-VID-004 | VID-004 | 原生字幕、短 ASR、超过 90 秒 ASR、无转写配置 | 文案来源明确；长视频有时间锚点；无配置失败关闭 |
| ACC-VID-005 | VID-005 | 默认请求与显式 6–12 帧请求 | 默认零帧；帧去重、有上限；未读取帧不得描述画面 |
| ACC-VID-006 | VID-006 | 时长、源文件、音频、文案、并发与留存超限 | 各边界在扩大副作用前拒绝或按权威规则收束 |
| ACC-VID-007 | VID-007 | 成功、写入失败、同源重跑与列举 | 原子发布；无半目录；稳定复用；投影无绝对路径和凭据 |
| ACC-VID-008 | VID-008 | 下载、转写和帧提取中取消或退出 | 流与完整进程树终止；Job 清理；无伪成功或自动重放 |
| ACC-VID-009 | VID-009 | 成功文案、成功三帧、失败和取消后安装 Skill | 只有真实成功来源在 30 分钟窗口内取得学习回执 |
| ACC-VID-010 | VID-010 | 干净工作树下载、校验、打包并启动 EXE | 两个 EXE 摘要与清单一致、位于包外资源目录、许可证存在且可执行 |
| ACC-VID-011 | VID-001, VID-003, VID-004 | 打包 EXE 中从 UI 粘贴/拖入链接到模型回答 | 使用真实配置完成同一会话分析和回复；错误、取消与进度可见；无残留进程 |
