# Session 验收矩阵

状态：基础项目会话已有第一条 Live（真实运行）证据；其余表格仍是 Executable Specification Draft（可执行规格草案）。

第一版只选择与 Cline 普通会话直接相关的基础场景。压缩继承、完整复制转移、侧聊、会话家族和高级导入导出场景全部延期，不得用它们阻塞第一条创作闭环；对应表格保留为未来验收库。

## 验收规则

- 每项验收引用一个或多个 `SES-*` 产品规则。
- Provider（模型服务）、网络、协议、权限、持久化和应用错误必须分别断言。
- 只有真实 Provider、真实持久化和真实进程重启可以形成 Live 证据。
- Mock（模拟）或 Fixture（测试夹具）只可验证 UI 投影与局部合同。
