- `ACC-ART-020..023`：生产 React 页面、单调 revision 去重、完整编辑、重复提交门禁、暂缓、拒绝确认、确定性导出和受限图片协议已由 Renderer 测试与隔离 Electron 验证。合法图片在真实页面加载；元数据、查询、穿越和冷启动后的哈希篡改均加载失败；精确状态码和响应头由协议自动测试验证。
- `ACC-ART-024`：批准、暂缓、驳回、正式分类、关键词导出和三次冷启动恢复通过，测试 Electron 进程残留为零；本次三种来源标记由真实 Service 状态机准备，不是普通会话中的 Agent 收集回合，因此“临时回合快照清理”只保留既有自动测试证据。

- `ACC-ART-025/026/029/030/031/032`：合同结构、分类证据和当前标签读取已自动验证；外部视觉模型的真实解读、分类理由、库级风格提取，以及移除原图后只凭换剧情 Prompt 的视觉保持均未运行，不标记 Live。

## Live 边界

自动测试可以证明真实文件、网络边界、图片解析、来源授权、工具配对和持久状态，但不能证明任意互联网搜索覆盖率或外部视觉模型理解质量。必须分别用真实公网图片、真实当前回合附件和真实当前项目图片完成普通会话候选摄入，并由支持视觉输入的正式会话完成至少一次候审提交，才能把三来源收集—识图链标为 Live（真实运行）。当前生产页面的批准、驳回、分类导出、重启恢复和受限图片协议已有隔离 Electron 证据；静态页面、Web Preview Fixture 或直接调用 Service 仍不能替代普通会话与外部视觉 Provider 证据。
