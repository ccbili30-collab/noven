# 诺文创作平台方向

状态：已确认的产品建设方向；不是功能完成声明  
更新日期：2026-08-13  
最高状态入口：[诺文权威状态](诺文权威状态.md)

## 一、平台使命

> **让每一个拥有生活、判断与想象的人，都能把只有自己知道的世界变成作品。**

诺文面向没有专业手艺、没有完整时间，甚至尚未把自己视为创作者的普通人。

目标关系是：用户可以从一句话、一段经历、一张图片、一条视频、一个梦、一次心动、一个遗憾或对既有作品的不满开始；作者房间拟承担用户此刻不愿或不能承担的专业创作压力；作品系统拟保存人物、事实、版本和取舍；作品获得读者回应后，回应与分支再成为创作材料。

目标平台闭环是：

```text
创作点火
→ 创作续航
→ 作品积累
→ 社会回应
→ 再创作
```

这不是“碎片化作品”，而是：

> **碎片化参与，连续性创作；随手开始，不是随手丢弃。**

当前闭环尚未实现。当前唯一接入用户界面的真实链仍是书记员v4路径契约展示：它只识别与组合，不执行主笔创作，消息与契约刷新即丢失。第一阶段只验证最小作者与作品闭环，不直接建设全部平台；完整状态以[诺文权威状态](诺文权威状态.md)为准。

## 二、平台面对的供给

诺文面对的不是一批缺少灵感的人，而是大量尚未进入作品生产的人类经验。

不同职业、地区、阶层和代际的人拥有不同的一手世界。他们未必会写小说，却可能拥有专业作者与现有模型无法凭空得到的细节、语言、矛盾和社会判断。

诺文要建立的关系不是：

```text
普通人提供人生
→ 平台提取数据
→ AI批量生产内容
```

而是：

```text
普通人使用自己的经验
→ 作者承担表达与制作压力
→ 平台不取得用户经历或作品的默认所有权
→ 用户保有保存、公开、授权和商业化的产品决定权
→ 作品抵达读者并可能产生价值
```

普通人是创作主体，不是素材矿。平台不主张用户经历或作品的默认所有权；用户保有对保存、公开、授权和商业化的产品决定权，具体著作权与其他权属仍依用户贡献、适用法律和有效协议确定。保存、公开、推荐、商业使用、平台训练和第三方模型训练必须分别获得相应授权。

如果创作过程资料在明确授权下形成长期积累，它可能帮助作者理解不同的人怎样看待自己的生活、为何保留或否决某种表达，从而更好地承接下一批人的创作。这是长期资料飞轮假设，不是当前已经形成的数据壁垒。

## 三、平台的四层结构

```text
诺文平台
→ 创作入口、作品、发布、回应、分支与权利关系

作者房间
→ 内化模型、工具、状态与流程复杂度

叛逆作者
→ 理解具体作品、作出取舍并承担结果

作品系统
→ 保存正文、事实、版本、来源与创作历史
```

### 1. 诺文平台

诺文是用户能够触摸的产品。目标能力包括：

- 从自然表达进入创作；
- 与同一位作者持续创作同一件作品；
- 保存、查看、恢复和发布作品；
- 获得阅读、追更、评论和关注；
- 在权利允许时建立分支并保留谱系；
- 让社会回应重新进入作者房间。

### 2. 作者房间

作者房间是黑箱边界，不是多个AI开会的用户界面。

内部可以组织：

- 用户意图与权限理解；
- 一个强模型或少数能力有高低的通用作者；
- 人物、时间线、版本、排版和多媒体工具；
- 作品事实与上下文装配；
- 检索、事实检查与必要复审；
- 提交、回退、取消和恢复门禁。

目标外部关系始终保持：

```text
用户 ↔ 同一位作者 ↔ 同一件作品
```

目标体验不要求用户管理模型、协调审稿流程或理解内部工具；当前主笔作者与完整工具链尚未接入。

### 3. 叛逆作者

叛逆作者不是风格皮肤，也不是故意反抗用户的角色。

它接受用户明确冻结的边界，承担用户交出的责任，同时对作品贡献新的观察、后果和审美判断。它反抗所有把具体作品压成平均答案的计算，包括大模型惯性、统一审美评分、推荐算法、商业效率和多数意见。

作者可以被用户改变，但不能在每轮交互中无痕消失为用户镜像。

### 4. 作品系统

作品系统让聊天真正成为作品，而不是一次次相互脱离的生成。

它必须区分：

```text
用户原始表达
探索与讨论
角色体验
候选版本
正式正文
已确认事实
废弃版本
来源与分支
```

用户可以主动吃书，AI不能因为遗忘无痕吃书。任何进入正式作品的变化都应有明确版本、影响和恢复路径。

## 四、创作点火

用户的起点通常不是完整作品计划，而是未成形的东西：

- “我不喜欢这个结局。”
- “我梦见一座每天换位置的城市。”
- “这个人每天收到明天寄来的信。”
- “这段经历我一直不知道怎样说。”
- “剩下的你来。”

第一轮不应先返回十个方向、人物表和复杂模式选择。作者要先承担一次具体创作决定，让用户看到：

> **作品已经开始发生。**

点火是否成功，不只看第一段是否流畅，而看用户是否产生第二次有效创作行为：

- 继续；
- 否决；
- 保护；
- 授权；
- 补入真实经验；
- 对人物和后果产生讨论。

Time to First Fascination（首次着迷时间）可以作为候选数据，但必须区分创作反应、修理AI和非创作操作，不能只优化第二次点击和廉价刺激。

## 五、创作续航

用户停滞可能来自完全不同的原因：

```text
没有可能性
→ 作者提供一个真正成立的新观察

可能性太多
→ 作者承担取舍，交付具体版本

方向明确但无法落笔
→ 作者承担表达和执行

用户想自己想
→ 作者保持克制，只阅读或回应
```

作者不能把用户已经交出的责任包装成更多选项退回去。

创作续航也不是不断增加反转、新设定和刺激点。作品能够继续，来自人物、关系、问题和后果仍然值得在乎。旧文档使用“创作势能”解释这种状态，但该术语没有被正式冻结，只能作为研究词，不能成为强制产品模型。

## 六、作品积累

用户可以每次只参与几十秒：

```text
第一天：说出一个念头
→ 作者形成开篇

第二天：只说“继续”
→ 作者承担下一段

第三天：说“这里不能动”
→ 保护一项作品选择

一周后：补入一段真实经历
→ 改变人物关系

一个月后：回来继续
→ 人物、事实和未完成问题仍然存在
```

连续性不能只依靠越来越长的聊天上下文。平台目标是形成最小正式作品状态：

- 当前正文；
- 已确认事实；
- 人物与关系状态；
- 用户保护项；
- 采用和废弃的版本；
- 未解决问题；
- 下一次进入点。

候选进入正式作品必须经过提交。重大变化对用户可见、可确认、可恢复。

作品可以结束、暂停、继续、产生分支或改编为其他媒介。长期连续性不等于永远续写。

## 七、基础作者与高级作者

诺文不建设大量“温柔、冷峻、古风、治愈”等风格作者。那只是把一个模板扩展成多个模板。

目标结构是少数能力有高低的通用作者：

### 基础作者

- 经济、高频；
- 负责点火、日常推进、局部修改和整理；
- 能面对广泛题材；
- 保证作品跨过基本可用线。

### 高级作者

- 在关键节点使用；
- 负责更深的经验理解、重大取舍、结构重写和最终精修；
- 判断什么不能被统一润色掉；
- 提高作品上限，而不只是写出更漂亮的句子。

两者是能力与成本分层，不是风格分类。用户选择的首先是快速创作还是深度处理，而不是先给作品套一层风格。

能力路由应由作者房间承担，不能让用户变成模型调度员。基础作者与高级作者能否保持同一作品身份，尚待验证。

## 八、人的参与与作品多样性

不同人生扩大作品“看见什么”的范围，不能单独解决少数模型“怎样写”的趋同。

趋同可能来自：

- 底层模型的语言和叙事惯性；
- 作者房间的统一流程；
- 审美复审删除非标准表达；
- 推荐系统奖励同一种开篇、反转和情绪。

平台的核心假设是：随着用户不断保留、否决、修改、补入经验，并接受或拒绝作者的意外，作品可能从AI对社会的普遍认识，逐渐深入个人对社会的具体反应。

> **一切作品终究是人眼中社会的倒影。**

作者要保护：

- 用户原话与地方性表达；
- 职业和生活细节；
- 用户对人物、权力、劳动、爱与尊严的判断；
- 那些不成熟、粗粝，却只有这个人会说出的东西。

平台不设一个统一“创新分数”裁决原创，也不把推荐反馈直接变成自动改稿命令。用户参与提高后，作品是否真的越来越像这个人，仍需长期真人验证。

## 九、以小说建立作品，以多媒体释放作品

小说适合第一阶段研究，因为它能集中检验人物、关系、因果、社会理解、审美取舍和长期连续性。自然语言也是普通人进入复杂创作成本最低的入口。

文字可以先沉淀作品的语义母体：

- 人物身份；
- 关键关系；
- 世界规则；
- 核心事件；
- 作者判断；
- 权利与来源。

漫画、音频和视频不是逐句转码，而是对同一作品的再解释。它们可以改变叙事顺序、视角、场景组织与节奏，但需要记录改变了什么、为何改变，以及是否形成新分支。

平台目标循环是：

```text
图片、视频、声音与现实经历触发创作
→ 文字建立人物、关系和世界
→ 多媒体重新表达作品
→ 社会回应产生新理解
→ 返回作者房间继续创作
```

稳定路线是：

> **以小说建立作品，以多媒体释放作品。**

多媒体不属于当前最小作者闭环，只有文字作品与作者关系验证后才进入真实建设。

## 十、社会回应

作品不仅需要完成，也需要抵达另一个人。

目标平台应支持：

- 阅读与追更；
- 点赞、收藏与关注；
- 评论、追问和争议；
- 对人物和另一种可能的愿望；
- 经授权的分支创作。

这些回应不自动修改作品，而是进入作者房间，成为新的观看位置。作者与用户决定吸收、拒绝、回答或分叉。

推荐系统不能只优化点击率、反转密度和热门题材，也不能让“市场读者AI”直接改稿。平台需要帮助有连续性、有人类影响和独立阅读价值的作品穿透供给，同时给地方性、非标准表达和仍在成长的创作者留下空间。

社会回应可能提高所有感、成就感和继续动力，但目前没有真实社区留存或推荐治理证据。

## 十一、穿过电子泔水

低门槛首先扩大供给，诺文早期很可能面对模型味、题材换皮、粗制滥造和大量无人阅读的内容。

电子泔水不是单纯“作品不好”，而是：

> **生成发生了，创作没有发生。**

平台方向包括：

- 私人探索保持自由；
- 探索、候选与正式作品明确区分；
- 公共发布需要用户阅读和确认；
- 不以生成字数和发布篇数奖励机器产量；
- 保留人的修改、否决和版本采用；
- 推荐关注真实阅读、追更、讨论和有效再创作；
- 检测大规模语言、结构和桥段近似；
- 不用单一审美模型裁定唯一正确文学。

诺文也不能制造AI尸块：不能把优秀作品拆成漂亮句子、桥段和风格零件，再缝成貌似完整的内容。AI应该从人类美学经验上长出新作品，而不是肢解人类作品进行拼装。

诺文真正的“抖音时刻”或“AI短剧时刻”，不是生成量爆发，而是过去不存在的创作者、作品类型和沉默经验开始成规模出现。这是一项长期目标，不是当前市场事实。

## 十二、Creative Fork Protocol（创作分叉协议）

当AI让任何人都能低成本继续别人的作品，平台既不能禁止所有二创，也不能把市场喜欢当成授权。

诺文希望借鉴GitHub的协作结构，逐步建立：

```text
作品仓库
＋ 开放创作协议
＋ 创作分支
＋ 差异记录
＋ 来源谱系
＋ 原作者关系
＋ 收益回流
```

### 1. 六层协议

- 法律层：允许复制、改编、发布与商业化的范围；
- 平台层：能否公开、搜索、推荐、进入活动与灵感库；
- 创作层：哪些角色、设定和情节可以改变；
- 关系层：自由演绎、设定兼容、原作者推荐、作者认可或正式世界；
- 经济层：署名、回链、授权费和收益分配；
- 谱系层：从哪里分叉、改变了什么、又产生哪些后续作品。

### 2. 必须坚持的边界

- 默认保护，开放由真实权利人主动选择；
- 允许创作不等于原作者认可；
- OOC（角色偏离原设）多数时候是审美和正统性关系，不能假装由AI或法律客观裁决；
- 市场喜欢不能代替授权；
- 公开分支保留来源和原作入口；
- 任何群体都不能替未参与的权利人授权；
- 商业价值按真实协议回到相关创作者。

### 3. 平台门禁

```text
创作前
→ 判断是否允许使用、改编与公开

创作中
→ 保留来源、差异和授权边界

发布时
→ 检查身份、传播与商业权限

产生收益后
→ 按协议回流价值

发生争议时
→ 保存证据并提供申诉
```

### 4. 起步方式

首批协议可以联合有影响力的作者、二创群体、编辑、版权机构、律师和高校团队共同制定，由他们为自己拥有权利的作品率先采用。

合作群体的影响力不能创造授权。文学涉及表达、角色、名誉、文化语境与商业衍生，只能借鉴GitHub的协作结构，不能机械复制软件开源许可证。

该协议目前只是产品方向，不是生效法律文本、行业标准或已实现功能。正式落地前必须经过专业法律审查。

## 十三、站外作品与公版边界

诺文无权替未授权站外作品授予改编许可。

当前保守方向是：

```text
未确认权利的站外作品
→ 只考虑进入私人创作沙盒
→ 不进入公共灵感库
→ 不主动推荐
→ 不商业化

公版作品、作者主动开放作品或明确授权作品
→ 才能进入公共分支网络
→ 强制保留署名与来源
→ 按协议决定推荐、商业化与收益回流
```

“标注二创、非盈利、不推流”只能降低部分传播与商业风险，不会自动取得改编权。

公版也不能只按出版年份猜测，需要根据适用法域、作者死亡时间、作品类型和具体版本核验。原作公版不代表现代译本、插图和有声版本同时公版。

## 十四、数据与训练

平台至少需要区分：

```text
运行当前作品所需数据
≠ 匿名产品统计
≠ 个人作者记忆
≠ 诺文内部评测或训练
≠ 第三方模型厂商训练
```

可能形成品味资料的信号包括：

- 用户在哪一句产生反应；
- 保留或删除什么；
- 拒绝哪些反转与解释；
- 采用、推翻哪个版本；
- 是否回来继续；
- 哪些人物得到真人记忆与讨论；
- 哪些作品产生有效分支。

这些信号只有在明确授权下才能用于对应目的，也不能把点击率、接受率和参与时长直接等同于文学质量。

允许训练的用户可以获得额外Token或能力，但基本创作质量不能以交出训练权为前提。授权撤回、既有模型影响、第三人隐私、职业秘密、脱敏、访问控制和近似复刻仍需专门治理。

## 十五、商业路线

平台的商业激励必须与创作价值一致：因作品被认真继续并产生真实社会价值而赚钱，而不是因机器批量生成内容而赚钱。

### 第一层：个人创作服务

```text
免费点火
→ Writing Plan（写作套餐）会员续航
→ 高成本作者与多媒体能力按量付费
```

用户购买的是一位长期负责作品的作者、持续作品状态和关键时刻的能力提升，不是模型名称。

### 第二层：创作者经济

作品获得真实读者后，平台才可能从阅读、打赏和经授权的衍生创作中收取服务费，并让价值回到原作者和分支作者。

### 第三层：平台服务

作者房间与作品系统成熟后，才考虑Writing API（写作接口）、官方IP创作空间和开放创作基础设施。

Writing API不能只是模型代理，必须包含作品状态、创作关系、授权谱系和反馈闭环，才可能形成独立价值。

当前没有真实价格、付费率、留存、单位成本、毛利、创作者分成、API或合作证据。商业路线仍是假设。

## 十六、技术原则

### 1. 作者房间随基础模型进步而变薄

更强模型可能替代大量编排机制。任何创作契约、检索、复审和模型路由都必须独立证明收益，否则删除。

### 2. 控制层与创作层分开

控制层负责：

- 权限；
- 资源；
- 状态；
- 版本；
- 提交；
- 失败、取消与恢复。

创作层负责：

- 理解作品；
- 审美判断；
- 具体取舍；
- 文字与叙事；
- 对结果负责。

控制层不能用图结构决定文学，创作层不能越过权限和事实。

### 3. 一个业务事实只有一个权威状态

提示词、聊天历史、作品账本和测试不能分别维护相互冲突的作品事实。长期作品需要可追踪的正式状态和版本关系。

### 4. 自有模型不是前提

顺序必须是：

```text
现有基础模型跑通真实闭环
→ 发现长期稳定缺口
→ 获得明确授权资料
→ 证明微调或训练更有效
→ 再决定是否建设自有模型
```

自有模型不能成为统一的“诺文好文”机器。它若存在，应更有经验和品味，同时更能保护具体人的差异。

## 十七、三阶段建设顺序

平台愿景很大，但建设必须串行。

### 第一阶段：最小作者闭环

目标：证明普通人能从一句话开始，不必管理复杂AI，并愿意继续同一件作品。

```text
自然表达
→ 作者交付具体版本
→ 用户自然回应
→ 有痕提交
→ 最小作品状态
→ 再次进入并继续
```

完成条件：

- 主笔真实执行；
- 用户可确认、否决、保护和授权；
- 正式作品与探索分开；
- 刷新和跨会话后作品仍然存在；
- 作者不越过冻结边界；
- 真人用户产生第二次创作行为并愿意回来；
- 作品跨过基本可阅读线。

### 第二阶段：作品与多媒体闭环

目标：证明作品能够形成更长连续性，并在不同媒介中保持身份和来源。

进入条件：第一阶段成立。

可能建设：

- 章节、人物与关系状态；
- 长期上下文装配；
- 基础与高级作者路由；
- 图片、漫画、音频和视频再创作；
- 跨媒介版本与差异；
- 作品完成、暂停、恢复和分支。

### 第三阶段：社会与开放创作闭环

目标：证明作品能获得真人回应，回应能推动创作，开放分支能给原作和新作者带来真实价值。

进入条件：前两阶段成立，并完成必要法律与治理准备。

可能建设：

- 发布、阅读、评论、关注与追更；
- 推荐与反趋同治理；
- Creative Fork Protocol；
- 作品谱系、授权与收益回流；
- 创作者经济与平台API。

不得因为第三阶段更具平台想象力，就绕过第一阶段最小作者闭环。

## 十八、平台成立的判断标准

### 用户侧

- 第一轮后是否主动说出第二句话；
- 第二句话是在参与创作还是修理AI；
- 是否能用“继续、不对、这里别动、剩下你来”推进；
- 是否认为作品中有自己的不可替代影响；
- 是否愿意回到同一件作品。

### 作品侧

- 是否跨过基本可阅读线；
- 人物、事实和版本是否连续；
- 用户回应是否进入正式作品；
- 作品是否越来越保留这个人的社会理解；
- 是否有人愿意读完、追更和讨论。

### 平台侧

- 作品数量增长后是否快速趋同；
- 用户经验经过作者房间后是否仍然存在；
- 推荐是否吞噬地方性和非标准表达；
- 公开分支是否保留来源并给原作带来价值；
- 平台收入是否来自创作价值而非机器产量。

作品质量与用户减负是两道独立门槛，不能互相抵消。社会指标不能替代授权，行为指标不能直接等同审美质量。

## 十九、当前停止边界

当前未获得以下真实证据前，不进入相应阶段：

- 未跑通主笔与最小作品状态，不建设完整社区；
- 未证明用户愿意继续，不扩张复杂作者架构；
- 未证明多模型带来增益，不固化多智能体拓扑；
- 未形成真实作品与读者，不建设大规模推荐系统；
- 未完成法律审查，不发布创作分叉协议；
- 未发现基础模型稳定缺口，不训练自有模型；
- 未获得明确授权，不把用户创作过程用于训练；
- 未获得真实付费与成本数据，不宣称商业闭环成立。

## 二十、最终方向

> **诺文不是用AI制造更多相似内容，而是用作者接住普通人的生活、判断和想象，让一次碎片参与持续成为作品。**

> **作者房间把复杂工具和模型内化，叛逆作者保护具体人的经验与作品判断，作品系统让每次选择能够长期存在。**

> **作品完成后进入社会，社会回应再次推动创作；在真实授权下，作品可以被继续，但来源、权利与原作者价值不能被抹去。**

> **诺文最终要形成的不是内容工厂，而是一张由普通人拥有、作者负责、读者回应、权利清晰的创作网络。**
