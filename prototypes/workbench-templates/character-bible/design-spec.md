# 角色圣经工作台视觉规格

状态：Prototype（原型）
参考图：`artifacts/character-workbench-template-reference/character-workbench-parchment.png`
目标视口：宽横屏参考为 `1672 × 941`；实际工作台以竖向阅读为主要适配方向。宽高比不超过 `6:5` 时进入纵向档案模式，不能只按窗口宽度判断。该页面仍是桌面工作台，不采用手机导航、手势或软键盘语义。

## 构图

- 页面使用暖象牙色羊皮纸底，四周保留约 `22px` 呼吸区，不显示应用侧栏、顶栏或工具栏。
- 上半区高约 `600px`。
- 人物立绘位于左侧 `7.5%–36.5%`，宽约 `486px`，高约 `578px`，使用旧纸毛边框和轻微投影。
- 人物档案位于右侧 `40.3%–94%`。姓名字号约 `70px`，身份副标题约 `27px`。
- 主要设定与人物关系并排，各占右侧内容区约一半；地域/势力归属在其下横跨整区。
- 角色圣经从约 `65%` 高度开始，横跨页面。标题居中，六个等宽模块横排，模块间以细金线分隔。

## 自适应模式

- **宽横屏，宽高比大于 `6:5`**：保持参考图的左立绘、右档案、下方六列角色圣经。
- **竖屏或近方形，宽高比不超过 `6:5`**：改为单一纵向阅读面。立绘居中置顶，身份和档案顺序向下；主要设定与人物关系在空间允许时保持两列，地域归属为两列，角色圣经为两列。
- **窄竖向窗口，宽度不超过 `620px`**：所有档案和角色圣经改为单列，仍保留完整内容，不折叠、不隐藏。
- 页面只有一个纵向滚动所有者；跨越布局阈值只改变 CSS 排布，不重建 DOM、不清空角色数据或阅读状态。

## 视觉

- 背景：`#ead8b4` 到 `#f4e7cc` 的不均匀纸色，叠加低对比纸纤维和边缘暗化。
- 主文字：`#3b2a1f`；标题酒红：`#6f201d`；装饰金：`#9b7436`；次级文字：`#735b42`。
- 中文标题优先 `STKaiti / KaiTi / Noto Serif SC`，正文优先 `STSong / SimSun / Noto Serif SC`。
- 线条 `1px`，避免现代卡片阴影、圆角 Dashboard（仪表盘）和输入框外观。
- 装饰只使用细线、罗盘、封蜡、地图轮廓和植物边花，不压过正文。

## 数据槽位

AI 只编辑 `character-data.js`：

- `name`、`subtitle`、`portrait`、`portraitAlt`；`portrait` 只能填写模板目录内的相对路径
- `profile[]`：主要角色设定
- `relationships[]`：人物关系
- `affiliation[]`：地域与势力归属
- `bible[]`：固定六类角色圣经，也允许增加或减少

Renderer（渲染层）只用 `textContent` 写入数据，不接受数据文件中的 HTML。空字段显示 `—`；缺失数组显示一个明确的空状态，不让页面脚本中断。

## 已知近似项

- 参考图中的人物立绘由图片模型生成；示例模板使用同图裁切，不代表正式角色资产。
- 浏览器可用字体与生成图的书法字体不会完全一致。
- 纸张纹理使用 CSS 生成，不复制生成图中的具体地图和植物线稿。
